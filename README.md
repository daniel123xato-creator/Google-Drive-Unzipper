# Google-Drive-Unzipper
Aplicativo nativo para macOS que descompacta e unifica arquivos particionados do Google Drive (-001.zip, -002.zip). Combina automaticamente todo o conteúdo em uma única pasta raiz, mantendo a estrutura de diretórios original intacta e removendo arquivos indesejados (__MACOSX/.DS_Store). Simples, rápido e com interface moderna.
